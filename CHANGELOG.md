# 2026-04-17 - SSH, статус-бар и кейбинды

- Добавлена поддержка `wezterm.default_ssh_domains()`; для SSH-доменов без multiplexing выставляется `assume_shell = "Posix"`, а `Leader + Shift + L` теперь открывает fuzzy-launcher по табам, workspace и SSH-доменам.
- Правый статус-бар полностью переделан и перенесён в `wezterm.lua`: теперь он показывает контекст активной панели (`SSH`/`SSHMUX`, workspace и текущую директорию), а SSH-хост определяется по domain name, shell integration и foreground `ssh`-процессу.
- Изменены клавиши разделения панели, теперь более логично для мнемонического запоминания:
  - `Leader + \` и `Leader + -` поменяны местами.
  - `Ctrl + h/j/k/l` стали `nvim`-aware: внутри `Neovim` уходят в редактор, вне его переключают pane WezTerm.
  - Убран прямой ресайз панелей через `Alt + h/j/k/l` и стрелки; ресайз остался в `resize_mode` и `pane_mode`.
- Добавлена навигация по prompt через `Shift + ↑` и `Shift + ↓`, а прозрачность окна теперь переключается между `0.96` и `1.0`.
- Изменены визуальные настройки окна: включена постоянная tab bar, уменьшены и выровнены `window_padding`, цветовая схема переключена на `Derp (terminal.sexy)`.
- Добавлено копирование в буфер правой кнопкой мыши.
- Дополнил и переписал комментарии к коду в `keybindings.lua`, полностью обновил `KEYBINDINGS.md` и расширил `README.md`, чтобы документация соответствовала текущему поведению конфига.

- Добавлен правый статус-бар с workspace, hostname, временем и укороченным `cwd`; формат табов теперь `№: заголовок` с обрезкой по ширине.
