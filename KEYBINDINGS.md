# WezTerm Keybindings

Документ перечисляет активные сочетания клавиш из текущего конфига `WezTerm`.

## Leader и правила записи

| Комбинация | Действие |
| --- | --- |
| `Ctrl-a` | Leader-префикс для терминальных действий |

- Таймаут Leader: `1000 ms`.
- Заглавные буквы означают `Shift`.
- `Ctrl-h/j/k/l` внутри `Neovim` передаются редактору, вне `Neovim` переключают панели `WezTerm`.

## Панели

| Комбинация | Действие |
| --- | --- |
| `Ctrl-h` | Фокус на панель слева |
| `Ctrl-j` | Фокус на панель снизу |
| `Ctrl-k` | Фокус на панель сверху |
| `Ctrl-l` | Фокус на панель справа |
| `Leader \` | Вертикальный split |
| `Leader -` | Горизонтальный split |
| `Leader z` | Зум текущей панели |
| `Leader q` | Закрыть текущую панель |
| `Leader g` | Выбрать панель |
| `Leader Shift-{` | Поменять текущую панель с выбранной |

## Режим ресайза

| Комбинация | Действие |
| --- | --- |
| `Leader r` | Войти в режим ресайза |
| `h` или `Left` | Уменьшить панель влево |
| `j` или `Down` | Уменьшить панель вниз |
| `k` или `Up` | Уменьшить панель вверх |
| `l` или `Right` | Уменьшить панель вправо |
| `Esc` или `Enter` | Выйти из режима |

| Комбинация | Действие |
| --- | --- |
| `Leader m` | Войти в режим панелей |
| `h` | Фокус на панель слева |
| `j` | Фокус на панель снизу |
| `k` | Фокус на панель сверху |
| `l` | Фокус на панель справа |
| `H` | Изменить размер панели влево |
| `J` | Изменить размер панели вниз |
| `K` | Изменить размер панели вверх |
| `L` | Изменить размер панели вправо |
| `g` | Выбрать панель |
| `{` | Поменять текущую панель с выбранной |
| `R` | Повернуть панели по часовой стрелке |
| `z` | Зум текущей панели |
| `q` | Закрыть текущую панель |
| `Esc` или `Enter` | Выйти из режима |

## Вкладки и workspace

| Комбинация | Действие |
| --- | --- |
| `Leader c` | Новый tab |
| `Leader x` | Закрыть текущий tab |
| `Leader n` | Следующий tab |
| `Leader p` | Предыдущий tab |
| `Leader 1..9` | Перейти к tab `1..9` |
| `Leader s` | Открыть новый shell в отдельном tab |
| `Leader w` | Назвать или выбрать workspace |

## Поиск и копирование

| Комбинация | Действие |
| --- | --- |
| `Leader v` | Copy mode |
| `Leader f` | Поиск по scrollback |
| `Leader Space` | Quick Select |
| `Shift-Up` | Перейти к предыдущему prompt |
| `Shift-Down` | Перейти к следующему prompt |
| `Right Click` | Скопировать выделение в системный буфер |

## Launcher и интерфейс

| Комбинация | Действие |
| --- | --- |
| `Leader Shift-p` | Палитра команд |
| `Leader Shift-l` | Launcher для tab, workspace и SSH-domains |
| `Leader o` | Переключить прозрачность окна между `0.96` и `1.0` |

- Tab bar видна всегда.
- В правой части строки показывается статус активной панели: `SSH host`, `SSHMUX host`, `WS name`, `DIR name`.
- В launcher доступны локальные вкладки, workspace, записи `SSH:host` и `SSHMUX:host`.

## macOS-сочетания
